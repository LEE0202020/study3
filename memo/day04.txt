1. URL Parameter(params)
	- 독립적인 고유 페이지/ 주소를 가져야 할 때
	ex) http://localhost:3000/react-query-01/1

2. Query String(useSearchParams)
	- 기존 페이지 안에서 필터링, 검색, 정렬, 탭 상태 등 부가 조건을 바꾸고 싶을 때
	ex) http://localhost:3000/react-query-01/read?id=1

Next의 Image
	1) 자동 최적화 및 포맷 변환 (Optimization)
	- 이미지를 브라우저가 지원하는 가장 가벼운 차세대 포맷(WebP, AVIF 등)으로 자동 변환해 줍니다.
	원본 이미지가 아무리 커도, 사용자가 보는 화면 크기에 맞게 리사이징해서 보내줍니다.

	2) 레이아웃 꿀렁임 방지 (CLS 방지)
	- 일반 <img>는 이미지가 다 불러와지기 전까지 크기를 몰라 화면이 아래로 툭 밀리는 현상이 발생합니다.
	Next.js Image는 width와 height(또는 fill)를 지정해 미리 공간을 확보하므로 화면이 덜컹거리지 않습니다.

	3) 지연 로딩 (Lazy Loading 기본 적용)
	- 사용자의 눈에 보이는 화면(Viewport)에 들어오기 전까지는 이미지를 아예 로드하지 않습니다. 초기 페이지 로딩 속도가 획기적으로 빨라집니다.

	4) 블러 효과 (Placeholder Blur)
	- 이미지가 로딩되는 동안 저해상도 블러 이미지를 먼저 보여주어 로딩 체감 속도를 줄여줍니다.

memoization
	- 함수형 컴포넌트에서 다른 변화 때문에 연산이 되는 불필요한 연산을 안하게 하기위해 사용한다.

useMemo란?
	- useMemo는 메모리에 있는 캐시를 사용하는 함수
	- 캐시에 있는 것을 쓴다는 것은 최초에 마운트를 할 때 연산결과를 캐시에 담아놓고
	리랜더링 있을 때 캐시와 결과를 비교하고, 내가 원하는 값의 변화를 줄 때만 연산을 수행한다. 
	이것을 memoization이라고 한다.

useCallback이란?
	- 함수 자체를 메모리에 캐싱(저장)하는 훅입니다. 자바스크립트에서 함수는 객체(Object)의 한 종류입니다. 
	컴포넌트가 리렌더링되면 내부의 함수들은 이름이 같아도 
	메모리상에서 새로운 주소값을 가진 '새로운 함수'로 다시 만들어집니다.
	캐시에 있는 것을 쓴다는 것은 최초 마운트(렌더링)될 때 만들어진 함수를 캐시에 저장해 두고, 
	리랜더링이 일어나도 의존성 배열([])에 지정한 값이 바뀌지 않았다면 새로 만들지 않고 
	캐시에 있는 기존 함수 주소를 그대로 재사용하는 것을 의미합니다.
